Frequently Asked Questions
LOXLEY Token

LOXLEY Token

⚠️

LOXLEY is not deployed. No token exists at any address on any chain, and no sale of any kind has been held. Nothing below is an offer.

What is LOXLEY for?

It is the collateral ciphernode operators bond in order to be eligible for committee selection, and the stake that gets slashed when an operator misses a duty. Bonding is the whole job.

Do I need LOXLEY to use Loxley?

No. Requesting a computation is paid for in the fee token — USDG, six decimals — not in LOXLEY. If you are building on the network rather than securing it, you never touch LOXLEY.

How does it launch?

Through a Pons pool on Robinhood Chain. There is no auction, no allowlist, no claim page, and no sale run by this project.

🚫

There is no official sale, presale, or claim portal for LOXLEY, and there will not be one before the token exists on chain. Anything presenting itself as one today is a scam, regardless of what it looks like or who appears to be running it.

When can I transfer it?

Immediately, always. There is no TGE gate, no cliff, no vesting contract and no transfer lock — not as a policy, but because the contract has no code that could impose one. lockedBalanceOf returns zero for every address, at every timestamp.

Can supply increase?

No. The full supply is minted once inside the constructor and there is no mint function. This is not a promise not to mint; there is no code path that mints.

Who controls the contract?

Nobody. It stores no owner and no admin role, and it is not behind a proxy. There is no upgrade, no pause, no blocklist, and no fee switch — so there is also no key whose loss or misuse could reach your balance.

What is the total supply?

1,200,000,000 LOXLEY, at 18 decimals.

Is it a governance token?

It carries ERC20Votes, so balance history is checkpointed and delegable, and the protocol uses that history for bonded-stake accounting. No governance system is deployed that consumes those votes today. If one is built, it gets documented here when it exists.

How do I verify any of this?

Read packages/loxley-contracts/contracts/token/LoxleyBondToken.sol. Once a deployment exists, verify the on-chain bytecode against that source rather than taking this page's word for it — the point of the design is that you do not have to trust the description.

Where do I bond it?

See Ciphernode registration for the bonding flow, and Tickets and sortition for how a bonded stake turns into committee eligibility.
