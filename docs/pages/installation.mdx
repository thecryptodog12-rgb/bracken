# Installation

This guide covers how to install the Bracken CLI and get your development environment set up.

## Prerequisites

Before installing Bracken, make sure you have the following dependency installed:

- [Rust](https://www.rust-lang.org/tools/install)

For full hardware and software requirements, see [System Requirements](/requirements).

## Quick Install (Recommended)

The easiest way to install the Bracken CLI is using our installer script:

```bash
curl -fsSL https://raw.githubusercontent.com/thecryptodog12-rgb/bracken/main/install | bash
```

Or if you prefer `wget`:

```bash
wget -qO- https://raw.githubusercontent.com/thecryptodog12-rgb/bracken/main/install | bash
```

This script will download and install `brackenup`, which is the standalone installer for the Bracken
CLI.

## Using brackenup

Once you have `brackenup` installed, you can manage your Bracken CLI installation:

### Install the Bracken CLI

```bash
# Install to ~/.local/bin (default)
brackenup install

# Install to /usr/local/bin (requires sudo)
brackenup install --system
```

Running `brackenup install` will install the latest version of the Bracken CLI. See
`brackenup --help` for more options.

### Update the Bracken CLI

```bash
# Update to the latest version
brackenup update

# Update system-wide installation
brackenup update --system
```

### Uninstall

```bash
# Remove the Bracken CLI
brackenup uninstall

# Remove system-wide installation
brackenup uninstall --system
```

## Install with Nix

If you use [Nix](https://nixos.org/) with flakes enabled, you can get a complete runtime environment
with no additional dependencies — Nix handles everything including installing the `bb` backend.

Get a devshell directly without installing it:

```bash
nix develop github:thecryptodog12-rgb/bracken/{branch,tag,commit}
```

This will build from source using the nix package manager and provide a runtime environemnt for
bracken. It might take some time but the result will be cached on your local nix store for future
execution.

```bash
❯ nix develop github:thecryptodog12-rgb/bracken/v0.2.2
❯ bracken --version
bracken 0.2.2
❯ bb --version
3.0.0-nightly.20251104
❯ echo $E3_CUSTOM_BB
/nix/store/6da5va1malbj4pjrzn5lan6n51m4hg9h-bb/bin/bb
```

NOTE: On first run, Nix will ask you to trust our binary cache. Say yes to both prompts to download
pre-built binaries instead of building from source:

```
do you want to allow configuration setting 'extra-substituters' to be set to '...'? y
do you want to permanently mark this value as trusted? y
```

If you decline, everything still works — it just builds from source, which takes longer.

## Manual Installation

If you prefer to install manually:

1. Visit the [releases page](https://github.com/thecryptodog12-rgb/bracken/releases)
2. Download the appropriate release archive for your platform:
   - Linux: `bracken-linux-x86_64.tar.gz`
   - macOS: `bracken-macos-aarch64.tar.gz`
3. Extract the binary and place it in your PATH (e.g., `~/.local/bin` or `/usr/local/bin`)
4. Make sure the binary is executable: `chmod +x bracken`

## Platform Support

| Platform | Architecture             | Status           |
| -------- | ------------------------ | ---------------- |
| Linux    | x86_64                   | ✅ Native binary |
| macOS    | Apple Silicon (M1/M2/M3) | ✅ Native binary |
| macOS    | Intel                    | ✅ Via Rosetta 2 |

_Note: Intel Macs automatically run Apple Silicon binaries through Rosetta 2 translation._

### Building from Source

If you need to build `bracken` from source:

1. Ensure you have Rust installed (using [rustup](https://rustup.rs/))
2. Clone the repository

```bash
git clone https://github.com/thecryptodog12-rgb/bracken.git
cd bracken
```

3. Build the binary

```bash
cargo install --locked --path ./crates/cli --bin bracken -f
```

## Verify Installation

After installation, verify that the Bracken CLI is working correctly:

```bash
bracken --help
```

You should see the help information for the Bracken CLI.
